# 🧠 Problem Solving Strategy

For every problem:

```text
1. Read the problem
        ↓
2. Understand the constraints
        ↓
3. Find the observation
        ↓
4. Think of an algorithm
        ↓
5. Estimate complexity
        ↓
6. Implement in C++
        ↓
7. Test edge cases
        ↓
8. Submit
        ↓
9. Review if wrong
```
